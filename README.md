# Portfolio Contact Backend

A simple and professional backend for a portfolio contact form built using Node.js, Express.js, MongoDB, and Nodemailer.

---

# Features

- Contact form API
- MongoDB database integration
- Email notifications using Nodemailer
- Environment variable support
- Input validation
- ES Module support
- Health check API
- Clean folder structure

---

# Tech Stack

- React
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- Nodemailer
- dotenv
- CORS
